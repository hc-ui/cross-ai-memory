One notebook for every AI you use

You told Cursor the folder this morning. Tonight Claude asks again. Next week Codex has never heard of it. The models are not stupid. Each product keeps its own black box.

Write the durable facts in notes you can open. Point every AI at the same notes. Let the model propose. You approve the write.

Three sentences

  1. 01Long-term memory lives in markdown you can open, not in a vendor brain.
  2. 02Cursor, Claude, Codex, and Grok all read the same folder.
  3. 03An AI may propose. It does not write until you say so.

Why this gets more useful

More people will use AI. More people will use more than one AI. Vendors will not sync last week's decision across Cursor and Claude. You need one notebook of your own, not six vendor brains.

Auto-memory fails dangerously: it writes the wrong note, then defends it. This method fails boringly: you forget to write a note.
