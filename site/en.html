Full changelog

The write gates

The method is in SPEC.md. Implementations may change. The gates should not.

  1. ReadSelf-contained questions skip the vault. Otherwise MEMORY.md, then the index, then the fewest notes. Default depth is standard. No full scan.
  2. WriteThe current message must say 记住 / approve write. Propose first. One note per topic. Hash the file before editing; stop if it changed.
  3. CheckAfter a write, run aimem check. Local commits use the batch id. Push needs a separate 同意推送.
  4. CollectThe collector only reads local sessions and writes a list. Its commit advances a checkpoint. Not git. Not a vault edit.

Conflicts: what you say now beats an old note. A fact just verified beats what a model remembers. Keep both sentences when they disagree. Do not silently overwrite.

What the CLI blocks

Zero dependencies. It flags broken links, duplicate titles, expired snapshots, unindexed notes, notes unreachable from MEMORY.md, and secret-like strings.

pip install git+https://github.com/hc-ui/cross-ai-memory.git

Why this is worth doing now

More people will use AI. More people will use more than one. Vendors will not sync last week’s decision from Cursor to Claude. You need one notebook of your own, not six vendor brains.

Auto-memory fails dangerously: it writes the wrong note, then defends it. This method fails boringly: you forget to write a note.
