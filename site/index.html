先读 MEMORY.md，再只打开索引点名的那几篇。
不要把整个文件夹读完。

去 GitHub 看完整方法

为什么现在值得做

用 AI 的人会越来越多。一个人同时用两家、三家，也会越来越普通。厂商不会帮你在 Cursor 和 Claude 之间同步「上周拍板的那件事」。你需要一本自己的记忆，不是六本厂商记忆。

自动记忆失败得很危险：它写错了，还接着用。这套方法失败得很无聊：你忘了写一条。
