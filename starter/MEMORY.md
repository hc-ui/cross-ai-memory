# 从这里进

这是唯一的入口。AI 不要把整本库翻完。

## 什么时候读

1. 自包含问题不要打开这本库。
2. 长期偏好、旧决定、本机路径、或接着上次的项目：先读 [[shared/INDEX]]，再只打开它点名的那几篇。
3. 不要一篇一篇读完。默认深度是 **standard**。

## 读到哪一层

| 深度 | 什么时候 | 打开什么 |
| --- | --- | --- |
| quick | 只要一个事实 | 本页加一篇 |
| standard | 接着做项目，或核对旧决定 | 共享索引，再加它点名的一两篇 |
| deep | 你说「仔细查」、有冲突、换了机器 | 对立笔记和最近的变更日志 |
